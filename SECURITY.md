# Security policy

## Reporting a vulnerability

Do not report security vulnerabilities in a public issue, discussion, pull request, or log.

Use GitHub's private vulnerability reporting for this repository:

`https://github.com/resolvrlabs/resolvr-typescript/security/advisories/new`

Include the affected version, impact, reproduction steps, and any suggested mitigation. Remove API keys, proxy credentials, cookies, CAPTCHA tokens, target-session data, and customer information before submitting evidence.

We will acknowledge the report through the private advisory, investigate it, and coordinate disclosure and remediation there. No fixed response-time commitment is made until the public security process is formally staffed.

## Supported versions

Before `1.0.0`, only the latest published prerelease is intended to receive security fixes. A stable support matrix will be added for `1.0.0`.
